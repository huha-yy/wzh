## 技术栈与约束
- 前端：React 18 + TypeScript + Vite、Ant Design（React）、React Router v6、Redux Toolkit（或 Zustand）、Axios、ECharts（echarts-for-react）
- 后端：Spring Boot 3.x（JDK 17）、MyBatis-Plus、MySQL 8、Jakarta Validation、JWT（Spring Security + 自定义过滤器）、Lombok、Logback、springdoc-openapi
- 数据库：采用 `docs/db/schema_no_fk.md`（无外键版本）作为唯一规范，保持字段、索引与约束一致

## 总体架构
- 前后端分离，RESTful API；RBAC 基于角色 `resident/admin/maintainer`
- 统一响应与错误码；统一分页与条件查询；接口文档基于 OpenAPI（Swagger UI）
- 事务边界与并发控制：库存锁定/订单创建/领取码生成同事务；验收/维修与库存恢复同事务；使用条件更新控制并发

## 后端实现计划
### 项目骨架
- Maven：`groupId=com.community.tools`，`artifactId=tools-sharing`
- 模块划分：
  - `common`：统一响应、异常、分页、拦截器、全局校验
  - `security`：JWT 鉴权、密码加密（BCrypt）、角色鉴权、权限注解
  - `system`：用户（users）、角色（roles）、用户-角色（user_roles）
  - `catalog`：分类（tool_categories）、库房（warehouses）、工具（tools）
  - `order`：订单（rental_orders）、明细（rental_order_items）、领取码（pickup_codes）
  - `maintenance`：维护记录（maintenance_records）
- 基础设施：MyBatis-Plus（Entity/Mapper/Service）、统一 ID 与时间字段映射、全局异常处理

### 关键业务与接口
- 认证：`POST /api/auth/login`、`POST /api/auth/register`、`GET /api/auth/profile`
- 用户/角色：`GET/POST /api/users`、`GET/POST /api/roles`、`POST /api/users/{id}/roles`
- 分类/库房/工具：`GET/POST/PUT /api/categories`、`GET/POST/PUT /api/warehouses`、`GET/POST/PUT /api/tools`、`GET /api/tools/{id}`（含搜索/筛选）
- 订单：居民 `POST /api/orders` 创建（含明细）；`GET /api/orders/mine`；`POST /api/orders/{id}/return/apply`
- 审核与领取码：管理员 `POST /api/orders/{id}/approve`；`POST /api/orders/{id}/pickup-code`
- 出库：库房 `POST /api/pickup/{code}/use`
- 验收/维护：`POST /api/orders/{itemId}/inspection/complete`（合格/不合格）；`POST /api/maintenance`、`GET /api/maintenance`

### 无外键一致性策略
- 服务层存在性校验：所有引用字段（如 user_id、tool_id、order_id）在写入前查询校验
- 事务与幂等：保证跨表原子性与接口幂等；避免重复扣减库存
- 条件更新：`UPDATE tools SET stock_available = stock_available - ? WHERE id=? AND stock_available >= ?`
- 级联处理：删除/停用逻辑由服务层完成（软删除或状态迁移）；定期离线审计孤儿数据

## 前端实现计划
### 项目骨架
- Vite + React + TS；目录：`pages/`、`components/`、`store/`、`router/`、`api/`、`hooks/`
- 主题与 UI：Ant Design；表格、表单、Steps、Result等通用组件
- 路由与守卫：React Router v6；基于 JWT 的鉴权与角色菜单控制

### 核心页面
- 登录页、仪表盘
- 工具目录：搜索/分类筛选/详情；下单页（数量、时长）；订单列表与详情（查看领取码、状态）
- 管理端：订单审核、生成领取码、安排验收；工具/分类/库房管理
- 维护端：领取码出库、验收工作台（合格/不合格）、维修记录
- 数据可视化：工具使用率、订单状态分布（ECharts）

### API 集成
- Axios 实例：请求拦截（携带 JWT）、响应统一错误处理
- `api` 层方法对应后端接口；`store` 管理用户信息、订单与工具的状态

## 验证与测试
- 单元测试：库存锁定、领取码生成、验收流转
- 集成测试：主流程与异常流程（库存不足、领取码过期、不合格维修）
- 压测：JMeter 针对下单/审核/出库接口
- 前端联调：本地代理 `/api`，检查路由守卫与角色菜单

## 运行与交付
- 数据库：执行 `docs/db/schema_no_fk.md` 的建表 SQL；提供种子数据脚本
